Selected work

Systems built. Assumptions tested.

Linux development tooling

Link Doctor

A Python CLI that diagnoses GNU static-archive link-order failures, identifies missed archive-member extraction, and proposes constrained repairs. Optional verification checks the proposed command with the native linker without overwriting the existing output.

Public source · Available on PyPI

Local media analysis tooling

Clip Sleuth

A Python CLI and Tk desktop application that finds a likely source and timestamp for a clip in a local video library. Uses NumPy, FFmpeg and ffprobe, with visual evidence, explicit uncertainty, resumable batch processing, and offline reports.

Public source · Linux preview download

Feasibility and usefulness investigation

Semantic retrieval without a GPU

A large-scale Project Gutenberg retrieval experiment: could it run without a GPU, what would it cost in time and storage, and would the results actually help? The index ran. The intended semantic use case did not hold up.
