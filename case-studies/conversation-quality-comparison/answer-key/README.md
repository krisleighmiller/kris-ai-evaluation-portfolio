# Answer Key and Calibration Record

[`answer-key.md`](answer-key.md) is the fixed qualitative evaluation key used for the three primary report evaluations. It was not present in the model-visible project directories during report generation. Each GLM evaluation received the completed report, the source context, and this key in a separate OpenCode instance.

The key defines required conclusions, evidence and grouping rules, treatment of unsupported findings, the three separate C016 contract determinations, and the rule against turning qualitative judgments into a numerical grade without a pre-agreed scoring scheme.

Calibration revision 1 followed an initial Luna test. That first evaluator over-weighted missing individual citations and assigned an informal numerical grade. The revision made grouped coverage and qualitative-only comparison explicit. The Luna rerun, Haiku, and Qwen reports were all judged under revision 1. See [Luna calibration history](../analysis/calibration-history.md).
