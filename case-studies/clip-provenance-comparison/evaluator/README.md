# Evaluator record

The evaluator layer was withheld from all three OpenCode trials. It was applied only after the saved trial artifacts had been selected.

## Truth and tolerance

- 200 clip names must appear exactly once.
- 160 clips have a known source within the 45 supplied masters.
- 40 clips were generated from material outside the supplied master library.
- A genuine proposal has the correct source when it names the expected master.
- A genuine proposal is jointly correct when the source is correct and the reported start is within **1.5 seconds, inclusive**, of the generated start.
- A foreign clip is explicitly rejected only when the workflow reports it as unidentified without a source or time.

The scorer keeps three concepts separate:

- **accepted:** the workflow's own ready-to-rely-on tier;
- **uncertain:** a candidate the workflow withheld from its accepted tier; and
- **unidentified:** no supported source assignment.

DeepSeek's native `confident` and `likely` labels are accepted because its report presents both as identified results. Astra and Kimi use only `confident` as accepted. The adapters do not relabel uncertain rows as accepted or convert diagnostic candidates into answers.

Files in this directory:

- `all-trial-scoring.json`: the original evaluator's row-level and aggregate output, retained as provenance. It uses its original field names, filename normalization, and numeric precision.
- `scored-artifact-manifest.json`: public paths and SHA-256 values for the exact artifacts scored.

The canonical public metrics are regenerated by the portable scorer in [verification/README.md](../verification/README.md) and recorded in [verification-results.json](../results/verification-results.json). That adaptation preserves the original verdicts while exposing accepted-tier rules, foreign rejection, and uncertainty composition more explicitly.
